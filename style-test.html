Test FAQ

테스트 자주 묻는 것

결과는 저장되나요?

로그인 없이도 브라우저에 임시 저장되어 다음 방문 시 동일한 결과를 다시 볼 수 있습니다. 회원이라면 마이페이지에 영구 저장되며 위시리스트와 함께 동기화됩니다.

결과가 마음에 들지 않으면 다시 할 수 있나요?

가능합니다. "다시 테스트" 버튼을 누르면 처음부터 다시 시작합니다. 무드는 매일 바뀔 수 있다는 전제 하에 설계되어 있습니다.

추가 쿠폰은 어떻게 받나요?

3문항 모두 응답 후 결과 화면이 노출되는 순간 자동 발급됩니다. 회원의 경우 쿠폰함에 즉시 등록되며, 비회원은 결제 단계에서 자동 적용됩니다.

결과를 친구와 공유할 수 있나요?

결과 카드 하단의 카카오톡 / 인스타그램 공유 버튼으로 공유 가능합니다. 받은 친구가 같은 타입을 선택하면 양쪽 모두 추가 적립이 발생합니다.
